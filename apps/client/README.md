# @mirage/client

App React (Vite + TypeScript) con dos puntos de entrada independientes:

- `/tablet` — flujo tactil del catalogo interactivo.
- `/pitch` — pantalla espejo para el equipo del pitch.

Ver el README de la raiz del repo para arquitectura completa, topologia de red e instrucciones de instalacion en sitio.

## Desarrollo

```bash
npm run dev --workspace @mirage/client
```
